# Bricks-2-Marble

Pre- and postprocessing tools for deep learning genome seq2seq models in Python.

## Installation

Download this repository and install it in a virtual environment.

    $ git clone https://github.com/gaius-augustus/bricks2marble
    $ cd bricks2marble
    $ python -m pip install -e .

If access to the AnnotationHMM tensorflow implementation is needed, specify this as a parameter
when installing.

    $ python -m pip install -e .[tf]
